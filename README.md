Factopia


Factopia is a website where you can read interesting facts about different topics like science, history, technology, and space. You can click on any topic to see facts appear one at a time, and the background colors change smoothly as you browse.



What You Need Before You Start
Before running this project on your computer, make sure you have these two things installed:

Python: A program that lets you run Python code.

Git: A tool to manage your project files.




Step-by-Step Guide to Run It Locally
Follow these exact steps to run the website on your own computer:



Step 1: Open Your Project Folder
Open Git Bash on your computer.

Go to your project folder by typing cd followed by the folder path where your files are saved. For example:

Bash
cd D:/Projects/Factopia
(Press Enter)



Step 2: Install Flask
Python needs a small package called Flask to serve your website pages properly. Type this command and press Enter:

Bash
pip install flask



Step 3: Start the Local Server
Once Flask is installed, start your server by typing:

Bash
python app.py
(Press Enter)

You should see a message saying the server is running at a web address (usually [http://127.0.0.1:5000](http://127.0.0.1:5000)).



Step 4: Open the Website in Your Browser
Open your web browser (like Google Chrome).

Type or paste this exact address into the address bar at the top:

Plaintext
http://127.0.0.1:5000
Press Enter, and your website will open. You can click on any topic button to view facts.
